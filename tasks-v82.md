## Notes for the coder
- **ZCode warning:** a second agent works in this tree — poll `git status` + file mtimes before every commit; never commit its untracked work.
- **Windows trap:** run tests with plain `node --test <file...>` (explicit files). `npx node` pulls a Node 26 shim that fails better-sqlite3 (`ERR_DLOPEN_FAILED`).
- `node --test test` (directory form) fails on Node 24 — always pass file paths.
- The full suite takes ~11 min (207 tests); run the targeted files on the card first.
- Secrets are config: never read or commit `.env`, `data/accounts.key`, `.wwebjs_auth/`.
